## What this is · นี่คืออะไร

An offering clock. Inside the carved teak is a small computer, an e-ink screen, and a
solar battery. It shows the time and many traditional calendars. It is built to run by
itself, without internet, for decades.

## The heartbeat check · การตรวจ “หัวใจเต้น” (MOST IMPORTANT)

On the main screen, near the moon, a small **dot steps to a new position every few
minutes**. If you watch for a few minutes and the dot **never moves**, the clock has
stopped and needs a power cycle (see below). A screen that looks correct but is frozen
is the one failure to watch for — the moving dot is how you tell.

## If the screen shows X, do Y · ถ้าหน้าจอขึ้นแบบนี้ ให้ทำแบบนี้

| Screen shows | Meaning | Do |
|---|---|---|
| "sleeping" face | battery low; resting to save power | wait for sun; clean the panel |
| dot not moving | possibly frozen | power-cycle (Phase 5 procedure) |
| time-confidence glyph | running on backup clock (no GPS) | usually fine; note if it persists |
| diagnostic / self-test face | a part failed at boot | see contact page |

*(Power-cycle steps, battery replacement (~8–10 yr), panel cleaning, and the contact
page are completed in Phase 5–6.)*
